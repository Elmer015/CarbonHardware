# Grid carbon intensity

`owid-carbon-intensity-electricity.csv`: Our World in Data, "Carbon intensity of electricity"
(g CO2e/kWh, Ember-based series), downloaded 2026-10-24 from
https://ourworldindata.org/grapher/carbon-intensity-electricity.csv

Used as the country-year CI(s,t) for location-based STEC. The current OWID series differs from
Table 5 of Zhang et al. (arXiv:2312.06364), e.g. Taiwan 2022 is 639 g/kWh here versus 561 g/kWh in
the paper; state which basis is used when reporting results.
